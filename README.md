# sheetmars.github.io

Source for my portfolio site, built with [Quarto](https://quarto.org) and served by GitHub Pages from `docs/`.

```bash
quarto preview      # live preview while editing
quarto render       # rebuild docs/ before committing
```

Each project lives in `projects/<name>/index.qmd` with its images next to it. The `order` field in the front matter sets its position in the listings.
